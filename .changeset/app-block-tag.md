Add `hk-app-block`: place a block from an app the store has installed (the subscribe button on a product page, the shopper's subscriptions page) in a themed page. Like `hk-inline-checkout` it prints only a same-origin frame of a platform page, so themes still have no scripts or form controls. The block is taken out of the page when the store has not installed the app.
