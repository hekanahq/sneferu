`<hk-variant-picker>` defaults to `display="auto"`: photo tiles when an option's values have images, colour dots when they have colours, plain buttons otherwise (an option set to buttons or dropdown stays that way). The default theme's variant-picker block and every example theme offer auto, swatches, buttons and select, with auto as the default.
