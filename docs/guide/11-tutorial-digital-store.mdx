# 11. Tutorial: build a digital products store theme

This tutorial builds **Bento**, a home page for a shop that sells printables,
templates and e-books as digital files, from a design mockup to a live store.
It uses only the CLI and the parts of Sneferu described in the earlier
chapters. The finished theme is live at
[demo-bento.hekana.com](https://demo-bento.hekana.com) (Arabic) and
[demo-bento.hekana.com/en](https://demo-bento.hekana.com/en) (English), and its
files are in the SDK repository under `examples/themes/bento/`.

The mockup was generated as a design brief. Its Arabic is placeholder text, and
its lavender and pink tiles become sky blue and peach.

The home page template lists the sections and seeds their repeated items
(tabs, shelves, list items, questions) as blocks, so a fresh install shows the
whole page. The excerpts show the first block of each section.

## 1. Plan the data

Before writing a template, decide what the page reads. Bento shows two
categories of products. Each shelf has a `collection` setting, so the merchant
picks the category in the editor; the theme's defaults are these handles:

| Handle | Shelf |
| - | - |
| `printables` | the first shelf |
| `templates` | the second shelf |

A store that has categories with these handles shows the page filled in on
install; any other store picks its own. Everything else on the page is a
product field (`title`, `url`, `price`, `image`), a setting, or a word from the
locale files.

## 2. Create the theme and the sample data

```bash
npx sneferu init bento
cd bento
```

Delete the starter's `sections/hero.snf`, `sections/featured.snf` and
`blocks/chip.snf`; the theme writes its own.

The dev preview's built-in sample products are game cards, and its only
collection is `featured`. To preview with this store's own products, write
`.sneferu-dev/data.json`. It can be split by locale, one block per language:

```json title="examples/themes/bento/.sneferu-dev/data.json (excerpt)"
 "en": {
  "store": {
   "name": "Daftar"
  },
  "collections": {
   "printables": {
    "title": "Printables",
    "products": [
     {
      "title": "Sunny colouring book",
      "url": "/en/products/sunny-colouring-book",
      "price": 6900,
      "compare_at": null,
```

That is the start of the `"en"` block; an `"ar"` block before it has the same
products with Arabic titles, so `?locale=ar` previews in Arabic. The folder starts with a dot, so it is never
part of the theme and never pushed. ([Getting started](01-getting-started.mdx)
has the details; it needs the CLI from Sneferu main after #16.)

## 3. Tokens

```json title="examples/themes/bento/theme.json"
{
  "id": "bento",
  "name": "Bento",
  "version": "1.3.0",
  "author": "Hekana",
  "description": "A soft pastel bento-grid theme for printables, templates and e-books",
  "category": "digital",
  "engine": "hk2",
  "engineCompatibility": "^2.0.0",
  "defaultLocale": "ar",
  "locales": ["ar", "en"],
  "settings": {},
  "tokens": {
    "colors": {
      "primary": "#1F2433",
      "secondary": "#74B8AE",
      "accent": "#E9946C",
      "background": "#FFFFFF",
      "text": "#1F2433",
      "muted": "#5F6474",
      "sage": "#CFE3D7",
      "peach": "#F7C9AF",
      "warm": "#FCF1EA",
      "sky": "#E8F1FA",
      "teal": "#74B8AE",
      "line": "#E8E6E1"
    },
    "layout": { "contentWidth": "1040px" },
    "fonts": {
      "heading": "Baloo Bhaijaan 2",
      "body": "Baloo Bhaijaan 2"
    }
  }
}
```

- `defaultLocale: "ar"` makes `/` Arabic, right to left; `/en` is English.
- Every colour the page uses is a token. The extra keys (`sage`, `peach`,
  `warm`, `sky`, `teal`, `line`) become `--hk-color-sage` and so on.
- No purple, lavender or pink anywhere: the mockup's lavender panel is `sky`
  and its pink tile is `peach`.

The font is a token: `"fonts": { "heading": "Baloo Bhaijaan 2", "body": "Baloo Bhaijaan 2" }`.
Baloo Bhaijaan 2 is in the font catalogue and has Arabic glyphs; Hekana serves
the files and sets the family on the theme root, so the stylesheet has no
`@font-face` and no `font-family`:

```css title="examples/themes/bento/assets/theme.css (excerpt)"
.bt {
  background: var(--hk-color-background);
  color: var(--hk-color-text);
  line-height: 1.5;
  min-height: 100vh;
}
```

## 4. Layout

```html title="examples/themes/bento/layout/theme.snf"
<div class="bt">
  <hk-section-group name="header" />
  <main><hk-slot name="content" /></main>
  <hk-section-group name="footer" />
</div>
```

The header and the footer are [section groups](18-section-groups.mdx):
`groups/header.json` and `groups/footer.json` start them with the sections
`bento-header` and `bento-footer`, and the merchant edits them once for the
whole store.

```html title="examples/themes/bento/sections/bento-header.snf"

        </div>

    </div>
  </div>

<hk-schema>
  {
    "name": "Header",
    "version": 1,
    "templates": ["header"],
    "settings": {
      "menu": {
        "type": "menu",
        "label": "Menu",
        "default": "main"
      },
      "drawer_on_add": {
        "type": "boolean",
        "label": "Open the cart when an item is added",
        "default": true
      }
    }
  }

```

- The page goes where `<hk-slot name="content" />` is.
- Cart links carry `data-hk-open="cart-drawer"`: with the controllers running
  they open `<hk-cart-drawer>`, without them they go to the cart page.
  `<hk-cart-count />` shows the number of items.
- All words are `t('…')`. Links go through `url()`: `url('/cart')` is `/cart`
  on an Arabic page and `/en/cart` on an English one. The language switch is
  `<hk-locale-switch />`: it links to the same page in the other language.
- The phone menu is `<details>`/`<summary>`: it opens without script.
- The menu panel starts with the store's own menu, `menu(section.settings.menu)`
  (the `main` menu unless the merchant picks another); see [Menus](20-menus.mdx).
- Icons are `<hk-icon name="shopping-bag" />` from the bundled set. The filled
  avatar has no match in the set, so it stays an inline SVG in
  `snippets/glyph.snf`.

## 5. The template

The template is the one shown at the top of this page: three sections, in

#### How it works

1. `collection(block.settings.list)` reads the collection the merchant picked
   for this shelf (`printables` and `templates` in the template). With nothing
   picked it is empty, and nothing is fetched.
2. `data-tone="{{ block.settings.head }}"` writes `peach`, `sage`, `sky` or `warm`. A
   template cannot build a `style="…"` from data (SN2009), so the colour comes
   from one CSS rule per tone: `[data-tone="peach"] { background: var(--hk-color-peach); }`.
3. `{% for p in collection(block.settings.list).products limit: 5 %}` draws
   the round thumbnails in the header tile; the covers use
   `limit: block.settings.count`, a `range` setting.
4. `{% if collection(block.settings.list).products %}` is false for an empty
   collection: the panel then shows one line of text instead of an empty grid.
5. `<hk-product-card product="{{ p }}" class="bt-card">` renders the cover, the
   title and the price as one link. The "New" badge is its `badge` part
   (`<hk-part name="badge">`), so it sits inside the link, before the image,
   and only on `forloop.first`.
6. The shelf's `id` is the collection handle, so the tab links `#printables`
   and `#templates` scroll to the shelves.

## 9. Check, preview and push

<Steps>
  1. `npx sneferu format` indents every file.
  2. `npx sneferu validate` prints `✔ theme bento@1.1.0 is valid`.
  3. `npx sneferu dev` and open `http://127.0.0.1:4100`, then
     `?locale=en`. Narrow the window below 640 px.
  4. Change `id` in `theme.json` to a slug of your own, then
     `npx sneferu push . --package <your-slug> --dev-store`.
  5. On a real store, create the two categories with the handles from step 1,
     or pick other categories for the shelves in the editor.
</Steps>

Only the home page is rendered by the theme in this release; product, category
and cart pages use the store's regular theme.

## What to know before you build your own

The three digital themes were first built on Sneferu 0.2 and moved to 0.3. What
is still missing:

| Limit | What the three themes do |
