# @hekana/prettier-plugin-sneferu

Prettier 3 plugin that formats Sneferu theme files (`.sneferu`), part of Sneferu, the theme language and SDK for Hekana stores.

```bash
npm i -D prettier @hekana/prettier-plugin-sneferu
```

`.prettierrc`:

```json
{ "plugins": ["@hekana/prettier-plugin-sneferu"] }
```

Docs: https://hekana.dev
