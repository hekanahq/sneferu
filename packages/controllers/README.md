# @hekana/sneferu-controllers

Part of Sneferu, the theme language and SDK for Hekana stores.

The only client JavaScript on a Sneferu theme page: variant picker, add to cart, cart count, cart lines, cart summary, cart drawer and product gallery. Themes cannot ship JavaScript; the commerce tags emit `data-hk-controller` hooks and this package upgrades them through a small host adapter.

Docs: https://hekana.dev
