# Contributing

Issues are welcome: bug reports, unclear docs, missing tags or filters, and
questions about building a theme. Please include the Sneferu version
(`npx @hekana/sneferu --version`), what you ran and what you expected.

Pull requests are by arrangement. Open an issue first and describe the change;
unsolicited pull requests may be closed without review.

Security problems: see [SECURITY.md](SECURITY.md), not a public issue.

## Working on the repo

    pnpm install
    pnpm build
    pnpm typecheck
    pnpm test

Docs live in `docs/` and are published on [hekana.dev](https://hekana.dev).
