# create-sneferu

Start a Hekana theme with Sneferu:

```bash
npm create sneferu my-theme
cd my-theme
npx sneferu dev               # preview on http://127.0.0.1:4100
```

`npm create sneferu <dir>` runs `sneferu init <dir>` from
[`@hekana/sneferu`](https://www.npmjs.com/package/@hekana/sneferu); the folder defaults to
`my-theme`, and options such as `--force` pass through.

Requires Node.js 20 or newer. Docs: https://hekana.dev
