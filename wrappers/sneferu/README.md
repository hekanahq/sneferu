# sneferu

The Sneferu CLI: build themes for Hekana stores. `sneferu` is the short name for
[`@hekana/sneferu`](https://www.npmjs.com/package/@hekana/sneferu); both install the same tool,
at the same version.

```bash
npx sneferu init my-theme     # copy the starter theme
cd my-theme
npx sneferu dev               # preview on http://127.0.0.1:4100
npx sneferu validate
npx sneferu build
```

Or install it once with `npm i -g sneferu` and run `sneferu` (or `snf`).

Requires Node.js 20 or newer. Docs: https://hekana.dev
